Let us study the code below and try to understand how's it working. 

public class MyClass{
    int x = 10; 
    public int metA(){
        int y = 20;
    }
    public void metB(){
        System.out.println(x); // correct and the output is 10
        System.out.println(y); // wrong - compile time error
}
So far we have always declared a variable inside a method - either main or any other method. Now if you look at the variable x, it is not declared inside any method. These variables belong to the object, which means, not to any particular method. These variables can be accessed from all methods in that class.
On the other hand, the variable y is declared inside the metA(). y belongs to metA() only and this variable cannot be accessed by any other methods except metA().
x is an instance variable and y is a local variable.
